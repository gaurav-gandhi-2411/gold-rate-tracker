### ADR 063 nowcast decision (dated 10-22)
- **Recorded:** run 39877575684, #3065.
  - 12 certified days; 4 late-IBJA days excluded.
  - Average miss: M3 Rs.29.06/g vs M0 Rs.35.07/g.
  - One-sided HAC-DM p 0.186.
- **Verdict:** does not hold. No promotion PR.
- **Rule check (10-28):** the pre-registered sources do not give a numeric pass rule.
  - ADR 063 says "a promotion PR is prepared after 2026-10-22, if M3 holds", and "nothing else in G3 changes: the arms,
    the test and the window".
  - `scripts/run_nowcast_shadow.py` (G3, #1983) says "prepare a promotion PR only if it holds on days that did not exist
    when it was chosen", using "the same one-sided HAC test R2 used". #1983's body says the same and adds: "A null
    result at n≈20 would not show that M3 is no better."
  - The threshold "M3 lower and p below 0.05" came from `docs/WEEKLY_ROUTINE.md`, which itself labels it an INFERRED
    reading.
  - R2 chose M3 as "significant under BH, not Bonferroni" across its candidates. A single pre-registered test has no
    multiplicity, so BH reduces to p below alpha.
  - p 0.186 fails every conventional alpha (0.05 and 0.10). The verdict stands under any reading, so nothing was re-run
    or re-decided.
  - The gap to report: the pass threshold was never written down.
  - Also INFERRED: with effective n this small, "does not hold" means "not shown", not "M3 is no better".

## Lessons for the next absence

1. **Anything that must happen while GG is away runs in GitHub Actions, and is proven on a real trigger before he
   leaves.** In this window, everything that ran without CC was a workflow: digest, Monday push, T19, the scrapes and
   syncs.
2. **The scheduled self-shift is not available.** The auto-mode classifier refused the `GRT-Autonomy-Shift` task.
   Do not plan an absence around Claude sessions starting on their own. Work that needs judgment either finishes before
   GG leaves or waits for his return.
3. **The laptop is the only Tanishq source.** If it is off, prices go stale, and no workflow can replace it. Before an
   absence, confirm it stays on and awake, or accept the gap.
4. **Write the pass rule down before the result exists.** ADR 063 said "if M3 holds" without a threshold, so the
   decision used an inferred one.
5. **Name the date of any weekly number in a daily message**, or it will read as stuck mid-week (#3286).
